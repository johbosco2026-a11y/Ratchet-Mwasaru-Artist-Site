# The Ratchet Mwasaru — Official Site



[**Open the live Vercel website →**](https://ratchet-mwasaru-artist-site.vercel.app/)



A visual artist portfolio and music landing page for The Ratchet Mwasaru, built in React and exported as a standalone static bundle for GitHub and Vercel.



## Contents



The site presents a music-first homepage with a Concrete Frequency editorial system: a Nairobi-rooted hero, selected releases linked to Apple Music, Spotify, and Audiomack, a visual archive, social links, and a direct booking CTA.



## Deployment



The production site is live at [ratchet-mwasaru-artist-site.vercel.app](https://ratchet-mwasaru-artist-site.vercel.app/). The repository contains the standalone `index.html`, `app.css`, `app.js`, local hero and brand-mark assets, and `vercel.json` routing configuration.



The artist catalog and social links are based on public pages. Biography copy intentionally stays concise and avoids unverified awards, labels, tour dates, or claims.
